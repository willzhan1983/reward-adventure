# 获得奖励冒险

一个适合苹果手机使用的本地优先成长打卡 PWA。女儿可以每天打卡、收集星星、查看连续天数并兑换奖励；规则和奖励可以在设置中调整。

## 本地运行

```bash
npm install
npm run dev
```

打开终端显示的本地地址即可使用。生产构建与预览：

```bash
npm run build
npm run preview
```

## 苹果手机使用

用 Safari 打开应用地址，点击分享按钮，选择“添加到主屏幕”。第一版数据保存在当前浏览器本地，不需要账号、密码或服务器。

## 数据备份

进入“设置 → 数据备份”，选择“导出本地备份”保存 JSON 文件。更换浏览器或设备后，使用“导入本地备份”恢复任务、奖励、打卡、积分和历史月份。

## 检查

```bash
npm test
npm run build
```

项目后续可以把本地存储适配器替换为云端同步，但第一版不会上传任何打卡数据。
